# Hotel-Project-Models

## Project Overview

This repository contains implementations of various machine learning and deep learning models applied to a hotel bookings dataset. The goal is to explore data patterns and predict outcomes such as booking cancellations, revenue, and customer segmentation.

## Directory Structure

- `association/`                : Apriori algorithm for association rule mining.
- `CNN/`                        : Convolutional Neural Network for regression tasks.
- `decisiontree/`               : Decision Tree and Random Forest classifiers.
- `hierachical_clustering/`     : Hierarchical clustering analysis.
- `k_mean_clustering/`          : K-Means clustering implementation.
- `KNN-DBSCAN/`                 : KNN and DBSCAN clustering methods.
- `naivebayes/`                 : Naive Bayes classification experiments.
- `regression_MLP/`             : Multi-layer Perceptron regression model.
- `regression_models/`          : Traditional regression techniques (OLS, GLS, GLSAR).
- `SVM/`                        : Support Vector Machine models.
- `Hotel_dataset_report.pdf`    : Detailed report of dataset exploration and model results.

## Data

This dataset is from the Hotel Booking Dataset, which can be found at https://www.kaggle.com/datasets/jessemostipak/hotel-booking-demand.

## Results

See `Hotel_dataset_report.pdf` for detailed EDA, methodology, and performance comparisons of all models.
